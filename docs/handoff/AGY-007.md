# AGY-007 — Channel templates and content calendar

## Summary

Migration `0005` seeds a shared catalog of 25 channel templates and the
character limit on every field. The families are Instagram (reel script,
caption, carousel outline, story sequence, creative brief), YouTube (long
script, short script, title set, description, thumbnail brief), LinkedIn
(post, carousel, case study, company update), Facebook (post, reel, promo
copy, community update), Website/SEO (blog outline, page brief, meta
title/description, internal links), and Google Ads (ad group plan, keyword
themes, RSA).

`POST /api/agency/channel-templates/{id}/validate` checks the draft against
those limits. A string is one value and a list is several. An over-long value,
too many values, or too few values comes back as `valid: false` with one
message per problem. The message states the length and the limit. It does not
include the text. The draft is not stored.

Google Ads RSA is headlines of at most 30 characters (3 to 15 of them) and
descriptions of at most 90 characters (2 to 4). Instagram captions are 2200,
YouTube titles 100 and descriptions 5000, LinkedIn posts 3000, Facebook posts
63206, SEO titles 60 and descriptions 160, and keyword themes 80.

`GET /api/agency/calendar/slots` lists one brand's slots in an inclusive start
range, optionally one channel. `POST /api/agency/calendar/slots` creates a
slot. `POST /api/agency/calendar/slots/{id}/reschedule` moves it. A second
live slot with the same brand, channel and start time is saved, and the
response sets `conflict` and names the other slots. Cancelled slots and slots
with no channel do not clash. The response says `published: false`. Linking a
content item does not change that item's workflow status.

## Assumptions

- The branch is `jarvis/agy-007`, lowercase, created from `jarvis/agy-005`
  (`2b5c8d4`). `origin/main` (`8ba215e`) has no agency package, so a branch
  from main would not compile. The pull request targets `jarvis/agy-005` so
  the diff is only this ticket. This environment did allow a new branch. The
  ticket name `jarvis/AGY-007` is the same branch in lowercase.
- The catalog is reference data, not a content, project, or campaign row, so
  `agy_channel_templates` and `agy_template_fields` have no `brand_id`. The
  same 25 templates are visible to every brand. A filled draft is not a row.
- Character count is Python `len` after stripping the ends. Internal spaces
  count. Blank entries are ignored.
- RSA asset counts (3–15 headlines, 2–4 descriptions) and the Instagram
  carousel size (2–10) are stored next to the character limits. The ticket
  named the character caps. The counts are the platform's asset counts so a
  valid RSA is not a single 30-character headline.
- Planning caps, where the platform does not publish a hard limit for that
  planning field, live in `agency/template_seed.py`. Facebook promo copy is
  125. Story frames are 80. Those are planning numbers.
- A conflict is the same `starts_at` instant for the same brand and channel.
  Overlapping ranges that start at different times are not a conflict.
  Cancelled slots do not occupy the time. The second slot is still saved.
  The warning is the point of the response, not a 409.
- `facebook`, `website`, and `google_ads` are channel kinds so a slot can name
  those platforms. Creating one does not connect an account. Down maps those
  kinds to `other` before the check narrows.
- Times are stored as UTC ISO text with microseconds. The range comparison
  uses that text. Naive datetimes are treated as UTC.
- SQLite 3.45.1 cannot drop the channel-kind check in place, and content items
  point at `agy_channels`, so `0005` carries `sqlite-fk:off`. The runner turns
  foreign keys off for that script only, then back on. Postgres swaps the
  check by looking up the kind constraint on `agy_channels`.
- No new runtime dependency. No LLM call. Tests use placeholder copy, not secrets.

## Known gaps

- Validating a template does not create a content item. The owner still writes
  the item through the content routes.
- A calendar slot does not move the content workflow and does not set
  `scheduled_at` on the item. The workflow schedule and the calendar are
  separate rows.
- Conflict detection does not treat overlapping windows as a clash.
- The range query refuses more than 500 slots instead of paging.
- Template text is not saved, so there is no revision history for a draft that
  only went through validate.
- Promo copy at 125 characters is a planning cap, not a live ads-account limit.

## Security impact

- New read surface for the shared template catalog, and new read/write surface
  for calendar slots, behind `X-Jarvis-Passcode` when a passcode is configured.
- Validate does not store the submitted text and does not copy it into the
  error. A calendar title that looks like a password or token is refused
  before insert, and that error does not include the value.
- A slot, reschedule, or channel filter for another brand does not return that
  brand's rows. A channel or content item from another brand is rejected.
- No broker, exchange, publishing, email, or ad-network calls. RSA validation
  does not create or change an ad. No secrets in code, tests, logs, or this
  document.

## Rollback

Drop the catalog and the extra channel kinds, leaving earlier agency
migrations in place:

```bash
python -m agency.migrate down --steps 1
```

That removes `0005`. `agy_channel_templates`, `agy_template_fields`, and
`idx_agy_slots_window` go away. Channel kinds `facebook`, `website`, and
`google_ads` become `other`. Calendar slot rows from `0001` stay.

```bash
python -m agency.migrate down
```

drops every `agy_` table when nothing remains applied.

To remove the feature from the app, revert the AGY-007 commits. Boot still
calls `migrate_up()`. While this code is imported, the next start applies
`0005` again if it is missing.
